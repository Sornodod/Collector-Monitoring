# 📊 SornMonitor - Self-Hosted Monitoring Collector

**SornMonitor** — это легковесный, самодостаточный сборщик логов и алертов, объединяющий данные от множества серверов в единую веб-морду с отправкой уведомлений в Telegram. Проект создан для тех, кто устал от сложных мониторинговых систем и хочет иметь простой, но мощный инструмент под полным контролем.

## 🚀 Основные возможности

### 📥 Централизованный сбор событий
- **Прием событий** по HTTP вебхукам от любого количества агентов
- **Очередь событий** с retry-механизмом при недоступности Telegram
- **Хранение истории** до 1000 последних событий

### 📱 Telegram интеграция
- Отправка уведомлений в **личные чаты** или **broadcast** всем подписчикам
- Настраиваемые типы уведомлений (успешные/неудачные подключения)
- **Антиспам** с настраиваемым интервалом

### 🌐 Веб-интерфейс
- Просмотр всех событий с фильтрацией по серверу, сообщению и статусу
- Управление **белым списком IP** (кто может слать события)
- Защищен **2FA** через Google Authenticator
- Поддержка **полного отключения** веб-морды

### 🔧 Управление через CLI
Интерактивное меню для управления коллектором:
1. Отключить веб-морду полностью
2. Включить веб-морду
3. Ограничить веб-морду локальным доступом
4. Обновить с GitHub
5. Включить 2FA
6. Отключить 2FA
7. Показать 2FA секрет
8. Сгенерировать новый 2FA секрет
9. Сменить логин
10. Сменить пароль
11. Управление белым списком IP
12. Показать логи
13. Отправить логи в Telegram
14. Логирование попыток авторизации
15. Настройка ротации логов
16. Проверка занятых портов
17. Показать статус системы

### 🛡️ Безопасность
- **2FA** через Google Authenticator (можно отключить)
- **Белый список IP** для отправки событий
- Логирование всех попыток авторизации
- Возможность полного отключения веб-интерфейса

### 📦 Простая установка
```bash
git clone https://github.com/Sornodod/SornMonitor.git
cd SornMonitor
chmod +x install.sh
./install.sh
```

### 🔌 Интеграция с серверами
Отправка событий с любого сервера
```shell
# Простой скрипт отправки
./send_event.sh "CPU 95%" true

# Через curl
curl -X POST http://collector:5000/webhook \
  -H "Content-Type: application/json" \
  -d '{"server":"web-01","message":"CPU 95%","error":"true"}'
```
### 🔧 Управление
Через systemd
```shell
sudo systemctl status sornmonitor
sudo systemctl restart sornmonitor
sudo journalctl -u sornmonitor -f
```
Через CLI менеджер
```shell
./sorn-monitor
# или
sornmonitor  # если добавлен алиас
```
Ручной запуск
```shell
./run.sh
# с отключенной 2FA для теста:
./run.sh --no2fa
```
